# TrustVault

Secure document sharing with a real audit trail.

## Current Status

Initial Express server setup.

## Run Locally

1. Install Node.js.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `node src/server.js`.
5. Open [http://localhost:3000](http://localhost:3000).

## Security

Authentication, document permissions, and audit logging will be implemented and tested in later stages.
